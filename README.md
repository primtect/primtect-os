# Primtect OS

> Первый, кто защитит.

Primtect OS — экспериментальная операционная система и системный слой для создания «живых» миров и ИИ-персонажей. Проект разрабатывается как единая архитектура низкоуровневых примитивов ОС и высокоуровневых игровых подсистем.

## Статус разработки

**Alpha — активная разработка.**  
Проект находится на стадии проектирования ядра и базовых подсистем. Код не предназначен для производственного использования.

**Лицензионное уведомление:**  
На текущий момент проект не имеет открытой лицензии. Исходный код является интеллектуальной собственностью разработчика и не предназначен для форка или коммерческого использования без согласования.

## Текущие цели
- Реализация загрузчика и стабильной последовательности загрузки ядра.
- Разработка подсистемы управления памятью (paging, allocators).
- Создание базового планировщика и примитивов синхронизации.

## Структура проекта
- `boot/` — загрузчик и низкоуровневые ассемблерные рутины.
- `kernel/` — ядро, системные вызовы, базовые абстракции.
- `lib/` — внутренние библиотеки и утилиты.
- `tests/` — низкоуровневые тесты и sanity-проверки.
